# Притяжение Земли — интерактивный фан-сайт

Полностью статический сайт: HTML + CSS + JavaScript. Сборка, npm и сервер для просмотра не нужны.

## Запуск

1. Распакуйте ZIP.
2. Откройте `index.html` двойным щелчком.
3. Для размещения на хостинге загрузите `index.html`, `style.css`, `script.js` и всю папку `assets/` в корневую папку сайта.
4. При необходимости используйте Live Server в VS Code для локального просмотра.

## Структура

- `index.html` — все блоки страницы и ссылки.
- `style.css` — дизайн, адаптивность, рваные переходы, анимации.
- `script.js` — интерактивность, анимации, прогресс, мини-игра, таймер, записки.
- `assets/` — локальные изображения.

## Важно

- Ссылка на Яндекс Видео открывает видео в новой вкладке. Встраивание чужого видеоплеера может блокироваться сервисом, поэтому используется надёжная кнопка перехода.
- Мнения записываются в `localStorage`: посетитель видит свои записи на этом же устройстве/в этом браузере. Для **общей** ленты мнений всех посетителей нужно подключить сервер/базу данных (например, Supabase или Firebase) и модерацию.
- Изображения — созданные для этого концепта иллюстрации. Это не кадры оригинальной серии.
- Проект неофициальный, права на персонажей и бренд принадлежат их правообладателям.
- Анимации отключаются или упрощаются при включённом `prefers-reduced-motion`.
